# Marky Remotion Promo

Code-generated launch/promo video for Marky using Remotion.

## Install

```powershell
npm install
```

## Preview

```powershell
npm run studio
```

## Render MP4

```powershell
npm run render
```

Output:

```text
out/marky-launch.mp4
```

## Render poster frame

```powershell
npm run still
```

Output:

```text
out/marky-poster.png
```

## Composition

- ID: `MarkyLaunch`
- Size: `1080x1920`
- FPS: `30`
- Duration: `12s`
- Style: Marky Reading Room brand; warm black, off-white ink, restrained blue accent.
